# Projet demo-app

Application Express.js de démonstration pour le TP CI/CD.

## Contexte technique
- Runtime : Node.js 20 LTS
- Tests : Jest
- Déploiement : Docker + Octopus Deploy
- Conventions : ESLint, commits conventionnels

## Consignes
- Générer du code simple, lisible et sécurisé
- Préférer un Dockerfile multi-stage
- Utiliser un utilisateur non-root dans l'image finale
